# Game and Feature Roadmap

This file records promising directions for FlyBike beyond the current levels.

## Game Concepts

- **Submarine Dive** — implemented; control depth through underwater hazards.
- **Dragon Flight** — implemented; follow aerial ring courses through fantasy landscapes.
- **Ski Jump** — build approach speed, then manage takeoff and landing effort.
- **River Rapids** — use effort to select currents and control downstream speed.
- **Space Lander** — translate pedaling into thrust for controlled planetary landings.
- **Train Engineer** — hold target power through grades while keeping a schedule.

## Platform Improvements

- Workout mode with interval targets layered over any level.
- Short per-level tutorials and live control previews.
- Adaptive difficulty based on recent completed runs.
- Achievements, daily challenges, and richer session summaries.
- Ride-history export with power curves, distance, settings, and scores.
- Ghost replays driven by a previous run's power trace.
- Multiple local rider profiles for shared trainers.
- Additional music, sound themes, and power-zone feedback.
